# lattice-refinement

Phase 3 of the lattice evolution. It defines how the organic solid is refined:
surface-coordinate adaptive sampling, deviation reporting, opening preservation,
quality budgets and benchmark evidence.

This proposal consumes the Phase 1 and Phase 2 contracts. It does not redefine
the cell distribution, the finish-quality field or the joint style.

The current quality profiles already choose resolution counts, but they are not
measured against a deviation or performance contract. This change makes those
choices auditable before any of them become a hard gate.
