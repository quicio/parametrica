## Types

- Shared `Vec2`/`CurveLike` shapes and a `CompiledExpression` contract.
- Warp expression derivation returns explicit `{ x, y }` strings.
- Boolean rings use `polygon-clipping` `Pair`/`Ring`/`MultiPolygon` types.

## Rules

- Expression compilation, error keys and fallbacks are unchanged.
- Clipping runs, boolean winding and meta roles are unchanged.
