# lattice-cell-contracts

Phase 1 of the organic lattice evolution. It introduces a normalized
`LatticeSpec`, a derived `LatticeNetwork` (nodes, edges, cells, openings) and a
metric-aware power-diagram distribution so cell size no longer depends on the
nominal radius or on the seed. The unrolled `X = θ·R_ref` metric is explicitly
an approximation, not a geodesic Voronoi.

The brief received ends at “Control…”; this proposal assumes control over
density, curvature, thickness, openings and manufacturing constraints. Confirm
before archiving.
