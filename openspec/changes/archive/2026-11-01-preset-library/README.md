# Preset library

Next OpenSpec slice after `parametric-surfaces` and the shipped preset catalog.

Read in order:

1. `proposal.md` — scope, capabilities and non-goals.
2. `design.md` — preview profile, cache, usage metadata and browser rules.
3. `tasks.md` — implementation phases and acceptance criteria.
4. `specs/` — behavioural deltas.

Scope summary:

- deterministic, derived preview thumbnails for built-in and user presets;
- lazy preview generation, cache and invalidation;
- persistent favorites and recent presets;
- thumbnail rows, Favorites/Recent filters and empty/loading states;
- accessible apply/star controls and focus handling;
- no document format change, no network, no filled previews.
