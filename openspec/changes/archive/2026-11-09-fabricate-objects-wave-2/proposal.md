## Why

The first object wave covered cups, pots, vases, a coaster and a totem. The
next objects need rectangular shells, blind holes, slots and keyholes, which
were specified as prerequisites.

- Add Lampshade 180.

- Add Soap Dish 120.
- Add Desk Tray 160.
- Add Napkin Holder 140.
- Add Wall Planter 120.
- Add Wall Hook 70.
- Allow Product preview for every exportable Fabricate solid, not only lattice
  and perforated bodies.

## Out of Scope

- Interlocking modular tiles.
- Sequential union-then-difference recipes.
- Slicer verification automation.
