# Visual goldens

Generated by `scripts/capture-lattice-goldens.mjs` at 1440×900.

- `lattice-network.png` — authored network of `Lattice Vase 200`.
- `lattice-solid.png` — prepared solid preview.
- `organic-solid.png` — prepared `Organic Lattice Vase 200` solid.

These are review artifacts, not pixel-exact CI snapshots. WebGL/canvas output
can differ by GPU and platform. Re-run the script after visual changes and
compare the silhouette, aperture readability and hierarchy rather than pixel
identity.
